Netflix Data Exploration Project
Project Overview

In this project, I explored a dataset about movies and TV shows available on Netflix. I used JupyterLab with pandas to load the dataset and examine the information to better understand the types of content on the platform.

Dataset

The dataset includes details such as the title, whether it is a movie or TV show, the release year, rating, and the country where it was produced. Each row represents one title on Netflix.

Analysis

Using pandas, I explored the dataset and created summaries and visualizations to understand patterns in the data. Some of the things I looked at included:

the number of movies vs TV shows

how titles are distributed by release year

which countries produce the most Netflix content

Key Findings

From the analysis, it was clear that Netflix has more movies than TV shows, most of the content comes from recent years, and a large number of titles are produced in the United States.

Conclusion

This project helped me practice exploring a real dataset and identifying patterns using JupyterLab and pandas.
