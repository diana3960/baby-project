In this project, I worked with a cleaned Netflix dataset and joined it with a country-to-region dataset. I used Python and the pandas library to load both files and combine them using a left join.

The Netflix dataset contains information about movies and TV shows such as type, release year, rating, and country. The country_regions dataset maps each country to its region.

The goal of this part of the project was to practice merging datasets using pandas. After joining the datasets, I saved the final merged file as merged_output.csv inside the results folder. This allowed me to see which region each Netflix title belongs to.
